# Put your PDFs here

DocuMind indexes every `*.pdf` in this folder. Drop in any documents you want to
ask questions about — manuals, papers, notes, contracts — and run the pipeline.

The original measurements in `.pdm/` were taken over two board-game rulebooks
(Monopoly and Ticket to Ride). Those PDFs are copyrighted and **not redistributed
here**, so this folder ships empty. Any PDFs work; the fixed demo question in
`config.py` (`FIXED_QUERY`) assumes a Monopoly rulebook, so adjust it for your own
documents.
